Online status

Online = last HEARTBEAT or last PONG within the last 10 minutes. v1 also included lastSeen (which updates on any status) — that wrongly marked devs as online right after a successful upload even if their service crashed.

Compliance week

Each week starts on Monday in the script timezone. A developer is compliant for the week when at least one SUCCESS row exists for that week.

Daily auto-generate

When a developer is first seen online on a given calendar day, a FORCE_RUN trigger is queued 10 minutes later so reports get uploaded automatically. Skipped for paused devs, devs that already have a trigger queued, and devs that already uploaded successfully today. Toggle from the Health page.

Reclamation / stall threshold

A developer is "stalled" when their last heartbeat is older than 24 hours (configurable via the stall_threshold_hours Script Property). The hourly auto-stall scan emails the admin allowlist once per stall cycle — a new alert fires only after the dev pings again.

Webhook authentication

Every uploader ping is HMAC-SHA256 signed with the shared secret. v2 tightened the replay window from 2 hours → 5 minutes, rejects future-dated timestamps (>60s ahead), and caches signatures during the validity window so a captured payload can't be replayed. Secret can be rotated via the hmac_secret Script Property (requires coordinated binary redeploy).
